# Repository role

This repository is the internal leaflet ingestion and review application for Šetřík.

Public consumer features belong in `Goshief/setrik-cz`. This app should focus on retailer discovery, leaflet intake, PDF processing, candidate extraction, quarantine/review, moderation, and publishing trustworthy offers into the shared Supabase data layer.

Do not duplicate public category, product-detail, shopping-list, or basket-optimization UI here unless it is required for internal review/testing.
